Usage: corpus [OPTIONS] COMMAND [ARGS]...

  CorpusRAG — unified learning and knowledge management toolkit.

  Run any subcommand with --help for details.

Options:
  --version  Show the version and exit.
  --help     Show this message and exit.

Commands:
  ask          Ask a question against a RAG collection.
  benchmark    Run performance benchmarks on a collection.
  doctor       Run health checks against configured...
  ingest       Ingest documents into a RAG collection.
  setup        Run interactive setup wizard for...
  summarize    Summarize a RAG collection.
  ui           Launch the CorpusRAG Web UI.
  collections  Manage vector database collections.
  db           Database management commands.
  dev          Developer utilities (setup, test, lint, build, clean,
               completion).
  orchestrate  Orchestration workflows for CorpusRAG.
  tools        CorpusRAG tools — RAG, video, handwriting, summaries, and
               learning.
